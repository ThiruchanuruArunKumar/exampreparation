# Exam Workflow

## Overview
The core product loop is:
1. Admin creates or edits an exam.
2. Student opens the exam and starts an attempt.
3. The exam runs under a timer and answer-saving system.
4. The attempt is submitted and scored.
5. Review and feedback are shown back to the student and admin.

## Main phases
- Exam setup and draft creation
- Exam information and attempt start
- Active exam-taking with timer and autosave
- Submission and auto-submit handling
- Results and review

## Supporting features
- Password-based access control
- Proctoring warnings and auto-termination
- AI summary and explanation support
- Parent-facing history reports
